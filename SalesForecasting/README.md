# SalesForecasting_Intern

## Contents
- `analysis.ipynb` — full notebook covering Tasks 1-6 (EDA, decomposition, 3 forecasting models,
  segment forecasting, anomaly detection, clustering). Runs top-to-bottom without errors.
- `train.csv` — Superstore sales dataset
- `vgsales.csv` — supplementary video game sales dataset (used in Task 5's multi-source practice section)
- `app.py` — Streamlit dashboard (Task 7), 4 pages: Sales Overview, Forecast Explorer, Anomaly Report, Product Demand Segments
- `requirements.txt` — Python dependencies
- `summary.docx` — 2-page executive business report (Task 8)
- `charts/` — all chart images generated by the notebook

## Running the notebook
```
pip install -r requirements.txt
jupyter notebook analysis.ipynb
```

## Running the dashboard locally
```
pip install -r requirements.txt
streamlit run app.py
```
This opens at http://localhost:8501

## Deploying to Streamlit Community Cloud (free)
1. Push this folder to a public (or private) GitHub repo — must include `app.py`,
   `requirements.txt`, and `train.csv` (the app reads `train.csv` from the same folder).
2. Go to https://share.streamlit.io and sign in with GitHub.
3. Click "New app", pick your repo/branch, and set the main file path to `app.py`.
4. Click "Deploy". The first build takes a few minutes while it installs everything
   listed in `requirements.txt`.
5. Copy the live `*.streamlit.app` URL it gives you — that's the link to submit.
